# STP connectome diagnostics

These are exploratory, single-seed runs of the real C. elegans connectome.
They all use base seed 12345 (reservoir seed 12346), leak 0.6, neuron bias 0,
and one fixed input scale selected from the grid with `--split 24`.

| Directory | Input scale | Gain rule | Recovery / facilitation (steps) | Update rate |
|---|---:|---|---:|---:|
| `real_seed_12345` | 0.1 | baseline: `(u*x/U)*W` | 10 / 50 | 1.0 |
| `real_seed_12345_input_1` | 1.0 | baseline: `(u*x/U)*W` | 10 / 50 | 1.0 |
| `real_seed_12345_raw_input_01` | 0.1 | raw: `u*x*W` | 10 / 50 | 1.0 |
| `real_seed_12345_raw_input_1` | 1.0 | raw: `u*x*W` | 10 / 50 | 1.0 |
| `real_seed_12345_raw_depressing_r50_f10` | 1.0 | raw: `u*x*W` | 50 / 10 | 1.0 |
| `real_seed_12345_raw_depressing_r100_f10` | 1.0 | raw: `u*x*W` | 100 / 10 | 1.0 |
| `real_seed_12345_raw_slow_input_1` | 1.0 | raw: `u*x*W` | 10 / 50 | 0.1 |
| `real_seed_12345_raw_depressing_r50_f10_slow` | 1.0 | raw: `u*x*W` | 50 / 10 | 0.1 |
| `fast_depression_20_seeds` | 1.0 | raw: `u*x*W` | 50 / 10 | 1.0 |
| `slow_depression_20_seeds` | 1.0 | raw: `u*x*W` | 50 / 10 | 0.1 |
| `slow_depression_holdout_20_seeds` | 1.0 | raw: `u*x*W` | 50 / 10 | 0.1 |
| `real_seed_12345_static_gain_u_input_1` | 1.0 | fixed `0.1*W` | none | none |

The raw gain rule is now the default. The baseline rule is retained for the
initial comparison; its division by `U` prevents initial release probability
from reducing recurrent weights. These conditions are examples rather than a
calibrated STP parameter sweep.

To reproduce a raw-gain input-scale-1.0 run from the repository root:

```bash
MPLCONFIGDIR=/tmp/matplotlib-thesis OMP_NUM_THREADS=8 MKL_NUM_THREADS=8 OPENBLAS_NUM_THREADS=1 \
python inv_arc_test.py \
  --job real --out-dir stp_demo/real_seed_12345_raw_input_1 \
  --ce-adj Connectome/ce_adj.npy --ce-ei '' \
  --unknown-sign-policy random_unknown_sign_matched \
  --ce-unknown-sign-weights Connectome/ce_unknown_sign_weights.npy \
  --seed 12345 --sid 0 --src-tag demo --n-repeats 1 \
  --split 24 --rank 4 --stp --stp-gain-mode raw \
  --stp-tau-recovery 10 --stp-tau-facilitation 50 \
  --stp-update-rate 1.0 --cuda -1
```

Use `--rank 0` for input scale 0.1. Add `--stp-gain-mode baseline` for the old
gain rule, or set `--stp-tau-recovery` and `--stp-tau-facilitation` for other
STP dynamics. The initial single-seed runs preceded the slower-update default;
their trace CSVs therefore do not have an `stp_update_rate` column. The new
20-seed runs do, and use seeds `12346 + 100000*k` for `k=0,...,19`.

The fixed-gain control uses the same initial effective scale as raw STP with
`U=0.1`. Its target radius is `0.1 * 78.165688 = 7.8165688`; this does not
use STP. Reproduce its 100-step saturation trace with
`python -m stp_demo.static_control_diagnostic` from the repository root.
The paired comparison figure comes from
`python stp_demo/plot_saturation_diagnostic.py`.

The trace samples the exact effective recurrent spectral radius, signed and
absolute mean weight over nonzero edges, and the 100-step fraction of
preactivations with `|pre| >= 2`. KR and GR use separate 10-step ensembles with
their STP states reset for each stream; they do not contribute to this trace.

## Slower-update pilot

For the same 20 seeds, input scale 1.0, leak 0.6, recovery 50, and facilitation
10, mean MC was 3.08 with update rate 1.0 and 4.32 with update rate 0.1.
The paired mean difference was +1.24 MC units (95% paired t interval
0.53 to 1.94; 16 of 20 seeds improved). The existing non-STP spectral-radius
1.05 condition averaged 4.04 MC on those same seeds; slow STP minus non-STP
was +0.27 (95% paired interval -0.67 to 1.22; 10 of 20 seeds improved).
The existing non-STP comparison is in
`final_results/main/combined.ALL.GRKR_PIL.csv` and uses the same raw
connectome matrix for each paired seed. The comparison plot is generated by
`python stp_demo/plot_slow_update.py`.

On a separate 20-seed set (`2012346 + 100000*k`, `k=0,...,19`) run after
choosing the slow depression setting, slow STP averaged 4.19 MC. The non-STP
radius-1.05 condition averaged 4.00 MC on those seeds. The paired difference
was +0.19 (95% paired interval -0.86 to 1.24; 11 of 20 seeds improved), so
this comparison does not establish an MC improvement over non-STP. The
non-STP per-seed best of the four radius settings averaged 4.35 MC, although
selecting a different radius for each seed is an optimistic comparison.
